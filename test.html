🧪 Nab Test Page

  1. Load the extension at chrome://extensions (Developer mode → Load unpacked)
  2. Drag each image below more than 50px
  3. Blue outline → green outline → success notification
  4. Then check your Downloads folder. The notification alone is not proof.

Two consoles matter: the page console (F12) for drag behavior, and the service worker console (chrome://extensions → Nab → "service worker") for download errors.
